# Лабораторна робота: профілювання та оптимізація програми

Програма — гра «Життя» Конвея ([src/life.c](src/life.c)) на полі 1024×1024, 1500 поколінь.

Що зроблено:

- побудовано FlameGraph програми й системи;
- зібрано статистику через `time`, `perf stat` і `perf report`;
- заміряно енергоспоживання;
- порівняно збірки `-O0` і `-O3 -march=native`: асемблер, час, FlameGraph, енергія.

Результат: після оптимізації програма працює приблизно в 47 разів швидше (10.7 с → 0.23 с) і витрачає приблизно в 50 разів менше енергії (328 Дж → 6.3 Дж).
